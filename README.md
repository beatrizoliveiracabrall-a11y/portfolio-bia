# Portfólio · Bia Oliveira (@biaa_oliveeira)

Site de portfólio para marcas: Sobre, Portfólio (Criação de conteúdo e UGC), Métricas e Parcerias.

- `index.html`: o site inteiro (HTML, CSS e JavaScript num arquivo só)
- `fotos/`: fotos do carrossel, capas dos reels e logos das marcas

Para atualizar trabalhos, números ou contatos, edite `index.html` e envie para o GitHub. A Vercel publica sozinha.
